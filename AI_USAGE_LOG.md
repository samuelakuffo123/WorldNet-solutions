**Team:** SEG26-76-1 WorldNet Solutions

## 🎯 Purpose

This document outlines how SEG26-76-1 WorldNet Solutions integrates Artificial Intelligence tools into our development workflow. We believe AI is a powerful assistant, but **never a replacement** for human understanding, creativity, and collaboration.

**Our Philosophy:**
> *"AI helps us write code faster. Understanding helps us write better code."*

---

## 🛠️ AI Tools We Use

| Tool | Purpose | Access Level |
|------|---------|--------------|
| **ChatGPT** | Research, explanations, debugging, documentation | Public (No client data) |
| **GitHub Copilot** | Code suggestions, boilerplate generation | Private (GitHub) |
| **Gemini** | Research, ideation, concept exploration | Public (No client data) |
| **Claude** | Documentation refinement, proofreading | Public (No client data) |

---

## 💡 How We Use AI

### ✅ Approved Use Cases

| Category | Examples | Tools |
|----------|----------|-------|
| **Learning & Research** | Understanding software engineering concepts, design patterns, best practices | ChatGPT, Gemini |
| **Code Assistance** | Generating boilerplate code, suggesting syntax, debugging errors | GitHub Copilot, ChatGPT |
| **Documentation** | Improving grammar, clarity, and structure of project docs | ChatGPT, Claude |
| **UI/UX Inspiration** | Generating design ideas, layout suggestions | ChatGPT, Gemini |
| **Problem Solving** | Exploring different approaches to technical challenges | All tools |
| **Testing** | Generating test case ideas, understanding edge cases | ChatGPT |

---

## 🚫 What We DON'T Use AI For

### ❌ Prohibited Use Cases

| Category | Reason |
|----------|--------|
| **Generating entire project** | Defeats learning purpose and may contain errors |
| **Submitting unverified work** | All AI output must be reviewed and understood |
| **Handling client data** | Confidential information stays offline |
| **Producing code we can't explain** | Every team member must understand their own work |
| **Creating final deliverables** | Human review is mandatory for all submissions |
| **Academic dishonesty** | All work must represent our own understanding |

## ✅ Team Agreement

We, the undersigned members of **SEG26-76-1 WorldNet Solutions**, agree to:

### 1. AI as an Assistant
- AI tools may **assist** but **cannot replace** our understanding
- Every team member must be able to explain their own work
- All AI-generated content must be **reviewed** before use

### 2. Transparency
- We will **record** all significant AI usage in this document
- We will be **honest** about where AI helped us
- We will **share** AI learnings with the team

### 3. Confidentiality
- **NEVER** paste client data, credentials, or private records into public AI tools
- **NEVER** share sensitive business information
- **ALWAYS** redact sensitive data before using AI

### 4. Accountability
- Any member unable to explain their own work may receive **zero individual credit**
- Team members are responsible for **reviewing** AI contributions
- All code must pass **human review** and **testing**

### 5. Academic Integrity
- All submissions represent our **own understanding**
- AI is a **tool**, not a **co-author**
- We take **full responsibility** for our deliverables
